# Whisker Rush

3-lane endless runner (cat vs. dog gang). Three.js + TypeScript + Vite.

- `npm run dev` local dev server
- `npm run build` typecheck + production build
- `npm test` unit tests (Vitest)

Design: `docs/GAME_DESIGN.md`. Build rules: `CLAUDE.md`. Deployed to GitHub Pages from `main` by `.github/workflows/deploy.yml`.
